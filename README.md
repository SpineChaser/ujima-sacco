## 🌍 Overview

Ujima SACCO is a harvest-cycle aligned, bias-free, human-in-the-loop
lending platform designed for Kenyan SACCO members — farmers, market
vendors, and informal traders who are systematically underserved by
traditional credit scoring.

---

## ✨ Features

- 🔐 **Auth** — Sign up / Sign in / Sign out with Kenya DPA 2022 compliance
- 📝 **Loan Application** — 4-step wizard with EMI calculator and harvest-cycle alignment
- 🦁 **Agent Simulation** — 3-agent AI pride (Scout → Guardian → Hunter) with live Claude API
- 💳 **Loan Payments** — M-Pesa STK Push + Card payment flows
- 📋 **My Loans** — Loan history with repayment progress and AI score rings
- 💬 **Jibu FAQ** — AI-powered SACCO assistant
- 👤 **Profile** — Privacy toggles, security settings, data export (Kenya DPA 2022)
- 🔒 **GUARD Safety Rails** — Kill switch, bias detection, Red Team testing

---

## 🤖 The Agent Pride

| Agent | Name | Role | Authority |
|---|---|---|---|
| 🌿 Scout | Karibu | Financial Literacy Coach | Max 3 SMS/day · never recommends loan amounts |
| 🔎 Guardian | Msaada | Loan Triage Agent | Auto-approve ≤KES 15K · 3+ flags to deny |
| 🏹 Hunter | Mwangaza | Human-in-Loop Coordinator | NEVER approves · briefings only |
